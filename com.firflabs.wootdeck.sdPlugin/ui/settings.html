Color Themes & background
Saved per action. Text uses black or white for contrast. An enabled Key Depth gradient takes priority while depth data is available.
Active means the observed profile is active, or a monitored key is pressed for Key Depth. Text contrast adapts automatically. Depth background gradients take priority when enabled.
Gradients blend by depth; Any Key uses the deepest pressed key. Threshold mode switches instantly at the configured actuation point. Any Key switches the background when any filtered pressed key reaches its own point. Missing configuration uses the static background.
Colors only the filled bar. Threshold mode uses each key's configured actuation point, independently of marker visibility. At or above the point uses the after color. Missing configuration uses the theme bar color. Foreground and background modes can be combined independently.
Profile box
Pixels at standard 72-pixel key size. Applies to the profile box. Outline styles use the box color for their lines and keep the tile background visible. Colors and shape are independent.
State colors
Colors are saved per action. Only the pressed Select/Cycle button previews the target with pending colors and a spinner. Other buttons show the observed state until confirmation. Pending defaults to blue; failures show an error on the pressed action.
Live key readings

The key shows up to three vertical bars side by side. Each bar fills from top to bottom, with the key name above and percentage below. The deepest presses appear first; extra keys are omitted. All active keys and their depths are listed below.

Animation
Applies to this key. State changes include profiles, connection/error states, and pressed/released keys. Continuous depth values and spinner frames do not restart the animation. Hardware commands run immediately; only the visual transition is animated.
Custom Themes

Stored plugin-wide. Includes fonts, colors, box style and display markers. Keyboard, profile, key filters, labels and travel calibration stay unchanged. Applying copies the design; later preset edits do not change other keys automatically.
